# AI Puzzle Solver

An interactive Artificial Intelligence project developed in Python that demonstrates different AI search and problem-solving techniques through classic puzzles, including N-Queens, Sudoku, and 8-Puzzle.

## Project Overview

The project explores how Artificial Intelligence techniques can solve different puzzle problems. It provides interactive gameplay and automated solving approaches using search algorithms and constraint satisfaction techniques.

## Puzzles and Techniques

- **N-Queens:** Hill Climbing and Backtracking-based approaches.
- **Sudoku:** Backtracking, Minimum Remaining Values (MRV), and Forward Checking.
- **8-Puzzle:** To be integrated.

## Technologies Used

- Python
- Object-Oriented Programming
- Artificial Intelligence Search Algorithms
- Constraint Satisfaction Problems
